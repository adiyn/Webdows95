# welcome to my cozy web corner ! (ﾉ◕ヮ◕)ﾉ*:･ﾟ✧

A retro Windows 95 desktop environment built in pure vanilla JS, HTML, and CSS (zero frameworks).

It acts as my personal portfolio, playground for web experiments, and an upcoming testing ground for C and Go systems (programming) tinkering.

### Live at https://adiyn.alwaysdata.net

## Features

    Win95 Desktop & Window Manager (draggable windows, desktop grid snapping with boundary checks & anti-stack rollback)

    Built-in stuff : MEMORY.EXE, SHIFUMI.EXE, fake file viewer, much more to come ! <(￣︶￣)>
